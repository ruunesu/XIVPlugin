# Dalamud Plugin Repository

This repository serves as the custom plugin repository hub for Dalamud plugins.

It hosts a `repo.json` that Dalamud uses to discover and install plugins distributed from individual plugin repositories.

## Installation

To install plugins from this repository:

1. Open **Dalamud Settings** (type `/xlsettings` in chat).
2. Go to the **Experimental** tab.
3. Under **Custom Plugin Repositories**, add the following URL and click **Save**:
   ```
   https://raw.githubusercontent.com/ruunesu/XIVPlugin/master/repo.json
   ```
4. Open the **Plugin Installer** (type `/xlplugins` in chat).
5. Search for the plugin you want and click **Install**.
